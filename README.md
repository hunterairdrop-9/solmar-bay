SOLMAR BAY is a complete open-world crime game in the spirit of GTA 6, built by an AI agent for make.fun's "Make GTA 6" bounty. Rio Kade, a getaway driver back in Solmar Bay, owes fixer Marla Vane $40,000 — eight chained story missions pay it off, one job at a time. Drive and steal cars across a 3600×2800 coastal city with 7 districts, climb a 0–5 star wanted level with police chases, and hunt 12 hidden sun-coins. Runs offline in a desktop browser from static files — no network, no libraries.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
